Web Page Technologies

1. HTML Lists

Introduction

Lists are used in HTML to organize related information in a structured and readable format. They are commonly used to display menus, steps, features and collections of items.

Types of Lists

  • Ordered List: Displays items in a numbered sequence.
  • Unordered List: Displays items using bullet points.
  • Description List: Used to display terms and their descriptions.

Example

<ol>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ol>

Ordered lists are useful when the order of items is important, while unordered lists are useful for general collections.

2. HTML Tables

Introduction

HTML tables are used to display data in rows and columns. Tables are useful for presenting structured information such as marks, schedules, product details and reports.

Important Table Tags

  • <table> – Creates a table.
  • <tr> – Creates a table row.
  • <th> – Creates a table heading.
  • <td> – Creates a data cell.

Example

<table>
    <tr>
        <th>Subject</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>Web Technology</td>
        <td>85</td>
    </tr>
</table>

3. Images in HTML

Introduction

Images make web pages more attractive and help communicate information visually. HTML uses the <img> element to display an image.

Example

<img src="image.jpg" alt="Sample Image">

Important Attributes

  • src: Specifies the location of the image.
  • alt: Provides alternative text for the image.
  • width and height: Control image dimensions.

4. HTML Forms

Introduction

HTML forms are used to collect information from users. Forms are commonly used for login pages, registration pages, search boxes and feedback forms.

Common Form Elements

  • Text input
  • Password input
  • Radio buttons
  • Checkboxes
  • Dropdown lists
  • Submit buttons

Example

<form>
    <label>Name:</label>
    <input type="text" placeholder="Enter your name">

    <button type="submit">Submit</button>
</form>

Forms allow users to interact with a website by entering and submitting information.

5. HTML Frames

Introduction

Frames were used to divide a browser window into multiple sections, where each section could display a different HTML document.

Traditional HTML frames are now considered outdated in modern web development. However, the concept is important for understanding the history of web technologies.

Iframe

An iframe is an HTML element that can embed another web page or document inside the current web page. 

<iframe src="page.html"></iframe>

6. Dynamic HTML and JavaScript

What is Dynamic HTML?

Dynamic HTML, commonly called DHTML, is a combination of HTML, CSS and JavaScript used to create interactive and dynamic web pages.

Role of Technologies

  • HTML: Provides the structure of the page.
  • CSS: Controls the appearance and design.
  • JavaScript: Adds behavior and interactivity.

Example

<button onclick="showMessage()">
    Click Me
</button>

<script>
function showMessage() {
    alert("Welcome to Web Technology!");
}
</script>

7. CSS

Introduction

CSS stands for Cascading Style Sheets. It is used to control the appearance and layout of HTML elements.

CSS can change colors, fonts, spacing, borders and the overall layout of a web page.

Basic CSS Syntax

h1 {
    color: blue;
    font-size: 30px;
}

Types of CSS

  • Inline CSS: Written directly inside an HTML element.
  • Internal CSS: Written inside a style tag.
  • External CSS: Written in a separate CSS file.

External CSS is useful because one stylesheet can control the design of multiple web pages.

8. Document Type Definition (DTD)

Definition

DTD stands for Document Type Definition. It defines the structure and allowed elements of an XML document.

A DTD helps ensure that an XML document follows a specific format and contains valid elements.

Example

<!DOCTYPE student [
    <!ELEMENT student (name, course)>
    <!ELEMENT name (#PCDATA)>
    <!ELEMENT course (#PCDATA)>
]>

9. XML Schemas

Introduction

XML Schema is used to define the structure and data rules of an XML document. It can specify which elements and attributes are allowed and what type of data they can contain.

Advantages

  • Defines the structure of XML data.
  • Supports different data types.
  • Helps validate XML documents.
  • Provides more detailed rules than basic DTD.

10. Object Models

Introduction

An object model represents the elements and structure of a document as objects. Programs can use these objects to access and modify document content.

In web development, the Document Object Model, or DOM, represents an HTML or XML document as a tree of objects.

Simple Example

JavaScript can use the DOM to find an HTML element and change its text, style or content.

11. Presenting XML

Introduction

XML is mainly designed to store and exchange data. To present XML data in a user-friendly format, additional technologies can be used to transform or style the information.

XML data can be processed and converted into formats that are easier for users to read, such as HTML.

Uses

  • Displaying structured data on web pages.
  • Exchanging information between applications.
  • Transforming XML data into other formats.

12. XML Processors: DOM and SAX

DOM Parser

The DOM parser reads an entire XML document and creates a tree structure in memory. Programs can move through the tree and access or modify different parts of the document.

SAX Parser

SAX stands for Simple API for XML. A SAX parser reads an XML document step by step and generates events when it finds different parts of the document.

DOM vs SAX

  • DOM: Loads the complete document into memory.
  • SAX: Processes the document sequentially.
  • DOM: Useful when the document needs to be modified.
  • SAX: Useful for processing large XML documents efficiently.

📌 Unit 2 Summary

Unit 2 introduces important technologies used to create modern web pages. HTML provides elements such as lists, tables, images and forms for structuring content.

CSS controls the design of web pages, while JavaScript helps create interactive and dynamic content. XML technologies, including DTD, XML Schema, DOM and SAX, are useful for representing, validating and processing structured data.
