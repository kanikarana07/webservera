WEB TECHNOLOGY - UNIT 4

Web 2.0 & Modern Web Technologies

Complete notes on Web 2.0, social and interactive web technologies, Web 3.0, semantic technologies and modern web trends.

← Back to All Units

1. Web 2.0

Introduction

Web 2.0 refers to the second generation of web technologies that focuses on user interaction, participation and content sharing. Unlike early websites that mainly displayed static information, Web 2.0 applications allow users to create, share and interact with content.

Main Features of Web 2.0

  • User-generated content
  • Interactive web applications
  • Social networking
  • Content sharing
  • Collaboration between users
  • Use of modern web technologies

Example

A social media platform allows users to create profiles, share posts, comment on content and interact with other users. This type of participation is a major feature of Web 2.0.

2. Blogs

Definition

A blog is a website or online platform where an individual or organization publishes articles, opinions, news or other information. Blog posts are usually displayed in a structured format and can be updated regularly.

Uses of Blogs

  • Sharing knowledge and information
  • Publishing personal opinions
  • Educational content
  • Business and product promotion
  • Technology and news updates

3. Wikis

Definition

A wiki is a collaborative website where multiple users can create, edit and organize information. Wikis are useful for building shared collections of knowledge.

The main feature of a wiki is collaboration. Authorized users can contribute information and improve existing content.

A group of students can use a wiki-like system to create and maintain shared notes for a subject.

4. Social Networking Sites

Introduction

Social networking sites are online platforms that allow users to create profiles, connect with other people and share information. These platforms support communication through posts, messages, comments and other interactive features.

Common Features

  • User profiles
  • Friends or connections
  • Content sharing
  • Messaging
  • Comments and reactions
  • Online communities

5. Technologies Behind Web 2.0: AJAX

Role of AJAX

AJAX is an important technology used in interactive web applications. It allows web pages to communicate with servers and update information without reloading the complete page.

This improves the speed and user experience of web applications. For example, search suggestions can appear while a user is typing without loading a new page.

6. RSS

Definition

RSS stands for Really Simple Syndication. It is a technology used to distribute and receive regularly updated web content.

Users can subscribe to RSS feeds to receive updates from websites without visiting each website separately.

Benefits of RSS

  • Provides updates in one place.
  • Saves time when following multiple websites.
  • Useful for news and blog updates.
  • Supports automatic content distribution.

7. Ruby on Rails

Introduction

Ruby on Rails is a web application framework designed to help developers build web applications efficiently. It is based on the Ruby programming language.

Main Features

  • Supports rapid web application development.
  • Uses a structured development approach.
  • Encourages reusable code.
  • Provides tools for database-driven applications.

Frameworks such as Ruby on Rails demonstrate how modern web development uses reusable components and organized application structures.

8. Open APIs

Definition

An API, or Application Programming Interface, allows different software applications to communicate with each other. An Open API provides access to specific functionality or data according to published rules and documentation.

Uses of Open APIs

  • Connecting different web applications.
  • Accessing external services.
  • Integrating maps, payments or other features.
  • Supporting innovation and software development.

A website can use an API to request information from another online service and display the results to users.

9. Web 3.0 and the Semantic Web

Introduction to Web 3.0

Web 3.0 is often associated with smarter and more connected web technologies. It focuses on improving how information is understood, connected and used by software systems.

Semantic Web

The Semantic Web is an approach in which data is provided with meaning and relationships so that software can process and understand information more effectively.

Benefits

  • Improves the connection between related information.
  • Supports smarter search and data processing.
  • Helps applications understand relationships between data.

10. Widgets and Mashups

Widgets

A widget is a small software component that performs a specific function. On the web, widgets can provide features such as weather information, calendars or interactive tools.

Mashups

A mashup is a web application that combines data or services from multiple sources to create a new service or application.

A travel website can combine map data, hotel information and weather details from different services.

11. RDF

Definition

RDF stands for Resource Description Framework. It is a standard used to represent information about resources and the relationships between them.

RDF is important in Semantic Web technologies because it helps describe data in a structured form that can be processed by software.

Basic Concept

Subject → Property → Value

This structure can be used to represent facts and relationships between different resources.

12. Web-Based Information Systems

Definition

A web-based information system is an information system that uses web technologies to collect, process, store and provide information to users.

Examples of Uses

  • Online education systems
  • Banking portals
  • Library management systems
  • Online shopping platforms

13. Search Engines

Introduction

A search engine is a system that helps users find information on the Internet. It processes search queries and provides relevant results from indexed web resources.

Basic Working

  1. Web pages are discovered and collected.
  2. Information is organized into an index.
  3. The user enters a search query.
  4. The search engine finds relevant information.
  5. Results are displayed to the user.

14. Recommender Systems

Definition

A recommender system is a software system that suggests products, content or information based on available data and user preferences.

Examples

  • Movie recommendations
  • Product suggestions
  • Music recommendations
  • Suggested educational content

Recommender systems help users discover relevant content and can improve the overall user experience.

15. Benefits of Blockchain in Web Development

Introduction

Blockchain is a distributed technology used to store records in a structured and shared manner. It can support web applications where transparency and decentralized data management are important.

Potential Benefits

  • Decentralized data management
  • Improved transparency
  • Data integrity
  • Support for decentralized applications

16. Edge Computing

Definition

Edge computing is an approach in which data processing is performed closer to the location where data is generated. This can reduce the need to send all data to a distant central server.

Benefits

  • Reduced response time
  • Faster processing for some applications
  • Useful for connected devices and real-time systems

17. Dark Mode in Web Development

Introduction

Dark mode is a user interface design option that displays a website or application using a darker background and suitable contrasting text.

Modern websites often provide users with a choice between light and dark appearance. A good dark mode design should maintain readability and visual consistency.

Basic CSS Concept

body.dark-mode {
    background: #1e293b;
    color: white;
}

📌 Unit 4 Summary

Web 2.0 introduced a more interactive and social approach to the Web. Technologies and platforms such as blogs, wikis, social networking, AJAX and RSS allow users to participate and share information.

Modern web technologies also include the Semantic Web, RDF, APIs, widgets, mashups and intelligent information systems. Blockchain, edge computing and user interface features such as dark mode represent important trends in modern web development.
