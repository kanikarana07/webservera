1. History of the Internet

Introduction

The Internet is one of the most important technologies of the modern world. It is a global network that connects millions of computers and other devices. Through the Internet, people can communicate, share information, study, shop and access many online services.

The development of the Internet started as a research project. Over time, computer networks became more advanced and different networks were connected together. This led to the development of the global Internet that we use today.

Important Development

  • Early computer networks were developed for communication and research.
  • ARPANET was one of the early computer networks.
  • TCP/IP helped different computer networks communicate with each other.
  • The World Wide Web made information easier to access through web pages.
  • Today, the Internet connects computers, mobile phones, servers and smart devices.

Simple Example

When you send a message using an online application, your device uses the Internet to communicate with another device or server located somewhere else in the world.

2. World Wide Web (WWW)

Definition

The World Wide Web, commonly called the Web or WWW, is a system of web pages and resources that can be accessed through the Internet. Users access websites using web browsers.

The Internet and the World Wide Web are not exactly the same. The Internet is the global network infrastructure, while the World Wide Web is a service that uses the Internet to provide web pages and information.

How the WWW Works

A user enters a website address in a web browser. The browser sends a request to the web server. The server processes the request and sends the required web page back to the browser. The browser then displays the page to the user.

Working Process

User → Web Browser → Internet → Web Server → Response → Web Browser

Main Components of WWW

  • Web Pages
  • Websites
  • Web Browsers
  • Web Servers
  • URLs
  • HTTP and HTTPS protocols

3. HTML

Introduction to HTML

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure web pages. HTML tells the browser what content should appear on a web page.

HTML uses elements and tags to organize content. Headings, paragraphs, images, links and tables can all be added to a web page using HTML.

Basic HTML Structure

<!DOCTYPE html>
<html>

<head>
    <title>My Web Page</title>
</head>

<body>
    <h1>Welcome to WebLearn</h1>
    <p>This is a simple web page.</p>
</body>

</html>

Common HTML Tags

  • <h1> to <h6> – Used for headings.
  • <p> – Used for paragraphs.
  • <a> – Used to create links.
  • <img> – Used to display images.
  • <ul> and <ol> – Used to create lists.
  • <table> – Used to create tables.
  • <form> – Used to collect user information.

Important Point

HTML provides the structure of a web page. CSS is generally used for design and styling, while JavaScript is used to add interactivity.

4. HTTP Protocol

Definition

HTTP stands for HyperText Transfer Protocol. It is a protocol used for communication between a web browser and a web server. It defines how requests and responses are exchanged on the Web.

How HTTP Works

When a user opens a website, the browser sends an HTTP request to the server. The server receives the request, processes it and sends an HTTP response containing the requested resource.

HTTP Request and Response

Browser: "Please send me the home page."
Server: "Here is the requested web page."

Common HTTP Methods

  • GET: Used to request data from a server.
  • POST: Used to send data to a server.
  • PUT: Used to update information.
  • DELETE: Used to remove information.

HTTPS

HTTPS stands for HyperText Transfer Protocol Secure. It is a secure version of HTTP that protects data exchanged between the browser and the server.

5. SMTP Protocol

Definition

SMTP stands for Simple Mail Transfer Protocol. It is mainly used for sending electronic mail from one system to another.

When a user sends an email, SMTP helps transfer the outgoing message from the sender's mail application to a mail server. The message can then be transferred to the receiver's mail server.

Simple Flow

Sender → Mail Application → SMTP Server → Receiver's Mail Server

Main Use

  • Sending emails
  • Transferring outgoing email messages
  • Communication between mail servers

6. POP3 Protocol

Definition

POP3 stands for Post Office Protocol Version 3. It is an email protocol used by an email client to receive messages from a mail server.

POP3 generally downloads emails from the server to the user's device. This allows the user to access downloaded messages from the local device.

Important Points

  • POP3 is mainly used for receiving emails.
  • It downloads messages from a mail server.
  • It is useful when a user wants local access to messages.

7. MIME

Definition

MIME stands for Multipurpose Internet Mail Extensions. It is a standard that allows email messages to contain different types of content in addition to simple text.

With MIME, an email can include images, documents, audio, video and other file types as attachments.

Uses of MIME

  • Sending file attachments through email.
  • Identifying different types of content.
  • Supporting multimedia content in Internet communication.

Example

When you attach a PDF or image to an email, MIME helps identify and transfer that type of content.

8. IMAP

Definition

IMAP stands for Internet Message Access Protocol. It is used by email applications to access and manage messages stored on a mail server.

Unlike traditional downloading approaches, IMAP allows users to access their email while keeping messages organized on the server. This can make it easier to use the same email account on multiple devices.

POP3 and IMAP

  • POP3 mainly downloads email messages to a device.
  • IMAP focuses on accessing and managing messages on the server.
  • IMAP is useful for accessing the same mailbox from multiple devices.

9. Domain Name System (DNS)

Definition

DNS stands for Domain Name System. It helps convert human-readable domain names into IP addresses that computers use for communication.

People find it easier to remember a name such as www.example.com than a numerical IP address. DNS works like an Internet directory that helps locate the correct server.

How DNS Works

  1. The user enters a domain name in the browser.
  2. The system looks for the corresponding IP address.
  3. DNS provides the IP address of the required server.
  4. The browser connects to that server.
  5. The requested website is returned to the browser.

Simple Example

Domain Name: www.example.com → DNS → IP Address → Web Server

10. Web Browsers

Definition

A web browser is a software application used to access, retrieve and display information from the World Wide Web. It allows users to open websites and interact with web pages.

Main Functions of a Web Browser

  • Sending requests to web servers.
  • Receiving web pages and other resources.
  • Displaying HTML content.
  • Applying CSS styles to web pages.
  • Running JavaScript code.
  • Allowing users to navigate between websites.

Examples of Web Browsers

Google Chrome, Mozilla Firefox, Microsoft Edge and Safari are examples of commonly used web browsers.

11. Web Servers

Definition

A web server is a system that stores website files and provides web pages to users when they request them through a browser.

When a browser requests a web page, the web server receives the request, finds the required resource and sends a response back to the browser.

Functions of a Web Server

  • Stores website files and resources.
  • Receives requests from web browsers.
  • Processes client requests.
  • Sends web pages and other resources as responses.
  • Supports web applications and online services.

Web Server Working

User → Web Browser → HTTP Request → Web Server

Web Server → HTTP Response → Web Browser → User

📌 Unit 1 Summary

In this unit, we learned the basic concepts of the Internet and the World Wide Web. HTML provides the structure for web pages, while protocols such as HTTP help browsers and servers communicate.

Email communication uses protocols such as SMTP, POP3 and IMAP. MIME supports different types of content in email messages. DNS converts domain names into IP addresses, while web browsers and web servers work together to deliver websites to users.
